# Figure legends

Generated by `s2f.evaluation`. Every number is reproducible from the JSON beside these files in `runs/<id>/eval/`.

**Figure 1. M1's sequence cap depletes the uncharacterised proteins that M2 is designed to select.** Proportion of each population surviving `--seq-cap` (default 4,000), which truncates by `m1_priority` rank. All CDS: 4,000/5,523 retained (72%). Hypothetical or uncharacterised CDS: 560/1,333 (42%), a 2.1-fold higher loss rate. `m1_priority` scores a hypothetical protein 0, so these sort to the bottom of the ranking the cap is applied to, while M2's `annotation_gap` component gives them weight 0.30. Labels give percentage retained and absolute counts.

**Figure 2. The two ranking scores select near-disjoint protein sets.** Rank under `m1_priority` (host-interaction evidence in the annotation) against rank under `triage` (structural tractability) for all 4,000 proteins scored by both. Dashed lines mark the top-50 cut used for selection; 6 of 50 proteins fall inside both. Spearman rho = +0.348. Diagonal streaks are blocks of tied scores resolved by the shared protein-length tie-break. Points are rasterised for file size; all other elements are vector.

**Figure 3. `annotation_gap`, not `pdb_evidence`, determines the shortlist.** Leave-one-out ablation of the eight `triage` components: each is set to zero, M2's own `triage_score_from_components` re-applied, and the ranking rebuilt. Bars give the number of proteins leaving the top 50; *w* is the production weight. 5 of 9 components alter the selection. Hatched bars mark components whose provider did not run in this configuration, which is a data gap rather than a measured null. No production weight was modified.

**Figure 4. The M3 structure-quality gate cannot discriminate between selections.** Precision of the `triage` top-50 against M3's `usable_for_docking` label (100.0%) beside the base rate of that label across all labelled proteins (99.3%): a lift of +0.7 percentage points. The gate passes almost every structure it is given, so high precision against it is not evidence of good selection. The comparison is also partly circular, since `pdb_evidence` contributes 0.40 to the triage score and the presence of a PDB hit is most of what makes a structure retrievable.
