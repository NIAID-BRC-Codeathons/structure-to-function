Structure to function

From a bacterial genome to a ranked, structure-backed shortlist of drug targets — and to the evidence behind every row.

Project 9

The problem

A new genome gives you thousands of proteins and no priorities

Roughly a quarter to a third of them are annotated hypothetical protein — which means nobody knows what they do, so nobody studies them, so nobody finds out.

The useful question is not what is every protein. It is which fifty are worth a structural and chemical look, and why.

Workflow

Six modules, one shared contract

Data flows one way. M2 may read M1; M4 may read M1–M3; nothing writes upstream. Every module is a CLI with a --dry-run that works offline.

M1 · genome

Genome in, annotated proteins out

APIs

  • www.bv-brc.org/api — features, genomes
  • Minhash Similar Genome Finder
  • p3- CLI fallback path

Filters

  • Codon-tree ingroup chosen from sequence, not taxonomy
InOut
contigs, or a CGA job directory m1/ three files · report.json keys run, genome, proteins · offline HTML report

M2 · triage

Every protein searched, then filtered hard

APIs

  • RCSB search/v2 sequence search + data GraphQL for entity metadata
  • AlphaFold DB prediction API
  • Foldseek web API (3Di+AA)
  • UniProt / UniParc, ChEMBL, STRING
  • DIAMOND locally — human proteome and essentiality references

Filters

  • Search: e-value < 1e-3, identity ≥ 25%, 25 rows
  • Counts as evidence: e-value < 1e-5 and coverage ≥ 50%
  • Foldseek: e-value < 1e-4, coverage ≥ 40%
  • Human homolog: DIAMOND 1e-5, coverage 50%; close at ≥ 40% identity
  • Essential ortholog: identity ≥ 40%, coverage ≥ 70%, e-value 1e-10
InOut
m1/ three files proteins.tsv (all 542) · top50.tsv · hits.tsv · kg.json · no_pdb_hit.tsv · run.json

M2 · triage

A transparent score, not a black box

0.40·pdb_evidence  + 0.20·virulence_amr + 0.15·essential
+ 0.15·drug_target + 0.30·annotation_gap + 0.10·surface_bonus
+ 0.10·ligandable_homolog
− 0.15·membrane_penalty − 0.25·(human_identity/100)

The first full HS11286 run selected 0 uncharacterized proteins out of 1,338 — a known target collects 0.50 from virulence, essentiality and drug-target evidence where a hypothetical earns 0.10. So annotation_gap went 0.10 → 0.30, with the sensitivity recorded rather than tuned quietly: 0.20→6, 0.25→9, 0.30→10, 0.35→15, 0.40→26 uncharacterized in the top 50.

Changed after seeing a run — so it is in the decision log, with the numbers, rather than quietly applied.

M3 · fold

Reuse a structure before predicting one

APIs

  • files.rcsb.org — experimental structures
  • AlphaFold DB — predicted models
  • 153 .cif collected for G37

Quality gate

  • PDB: identity ≥ 25%, coverage ≥ 50%, resolution ≤ 3.5 Å
  • AFDB: mean pLDDT ≥ 70, coverage ≥ 80%
  • Local pLDDT < 70 masked as low-confidence regions
InOut
report.json proteins + M2 xrefs structures/ · per-structure pass/fail with the evidence behind it

The finding

Our top hit was the genome matching itself

The top-ranked G37 protein was a hypothetical, matched at 100% identity to PDB 1Q8C_1 — Mycoplasmoides genitalium P47. The same organism.

Best hit is the…Top 50Whole genome
same species3034
same genus47108

88% of every same-species hit in the genome landed in our top 50. The ranking is not wrong — a 100% identity hit is the strongest evidence there is — but it is easy in a way a novel genome will not be.

The finding

What we did about it

Flags, not penalties. The score is unchanged; what changes is what the report is allowed to claim. Each protein now says so in words, so a reader is told when an annotation was easy instead of being sold it as a discovery.

Do not calibrate the weights on this genome. Written into the docs as a standing rule, because this identity distribution does not exist elsewhere.

One detail that decided it: BV-BRC writes Mycoplasma genitalium where the PDB says Mycoplasmoides genitalium. Compare genus strings naively and every self-match is marked foreign — the exact opposite of the truth, silently.
