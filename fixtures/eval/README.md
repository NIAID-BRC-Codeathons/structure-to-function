# `fixtures/eval/` — truth sets and the evaluation dry-run report

Backs `s2f/evaluation` and `tests/test_eval_*.py` (issue #49). Nothing here touches the
network; `docs/08-evaluation.md` is the protocol.

## `kpneumoniae_hs11286.truth.tsv`

223 curated gene symbols for *Klebsiella pneumoniae*: 115 `positive`, 97 `negative`,
11 `excluded`. Columns are `symbol`, `label`, `class`, `basis`, `note`; a row without a
`basis` is refused at load, because a call nobody can defend is not ground truth.

**Built from gene-family literature, not from this genome's annotation text.** That is the
whole design constraint: `m1_priority` is computed from `gene + product + classifications`,
so a truth set read off the same product strings would be scoring `MECHANISM_RULES` against
itself. See "Leakage" in `docs/08-evaluation.md`.

`excluded` is not a dumping ground. It records a call deliberately not made, with the
reason, so a reviewer can see where the literature is unsettled. `traT` is the worked
example — issue #49 lists it as a false positive, the complement-resistance literature
disagrees, and counting it either way would put an unargued claim in the numerator.

The set is **species-scoped**. The `virB*` rows are negatives because on an IncF plasmid in
an enterobacterium a T4SS is conjugation machinery; in *Legionella* or *Brucella* it is a
host-directed effector translocator. Reusing this file for another organism would be wrong.

### Refreshing it

Add rows; never silently reclassify one. A label change moves a measurement, so it belongs
in its own commit with the reason in the message, and any `metrics.json` taken under the
previous file is no longer comparable — the manifest records the truth set's SHA-256 so
that is detectable rather than assumed.

## `report.fixture.json`

39 proteins in a trimmed *K. pneumoniae* HS11286 shape, each carrying a real `m1_priority`
record. Generated by running `priority.rank_proteins` over the feature list rather than
hand-written, so the fixture cannot drift from what M1 actually emits.

The slice is chosen so every path in the harness fires on realistic annotation text:

| Proteins | What they exercise |
| --- | --- |
| `fimD` `fimH` `mrkD` `mrkA` `iutA` `fyuA` `tssL` `tssJ` `acrA` `acrB` | true positives with curated VFDB/CARD evidence behind the score |
| `wza` `wzi` `wzc` `ureC` `ompA` | true positives scored on product text alone — what the leakage audit counts |
| `skp` `ppiD` `traS` `virB6` | the four false positives issue #49 found in the top band, by name |
| `surA` `bamA` `secA` `secY` `traB` | their families, to show the failure is a class and not four accidents |
| `pemK` `ccdB` | plasmid addiction toxins, which match `MECHANISM_RULES["toxin"]` on the word "toxin" |
| `traT` | the `excluded` path: present, matched, counted in neither set |
| `tonB` plus an unnamed *TonB-dependent siderophore receptor* | the hyphen trap, end to end: only the first may match `tonB` |
| an unnamed *ATP-dependent protease* | the `ent`-inside-a-word trap from the issue |
| `rpoB` `murA` `gapA` `thrA` and three hypotheticals | unlabelled proteins, which must not count against precision |

Symbols in the truth set with no protein here (`rmpA`, the `iro` and `iuc` loci, most of
the Sec and Tra regions) exercise the not-present path, which drops them from the recall
denominator instead of scoring them as misses.

Regenerate by editing the feature table and re-running the generator recorded in the PR for
issue #49; the fixture and any test asserting on it change in the same commit (pitfall #18).

**Fixture numbers are not a result.** 39 proteins is a plumbing check. Every figure quoted
anywhere outside the tests comes from a full run, the way `fixtures/genomes/mgen_G37/` is
a shakedown genome and never a reported finding.
